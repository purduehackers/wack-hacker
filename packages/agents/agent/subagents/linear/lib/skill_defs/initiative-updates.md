description: Query, create, and update initiative status updates.
---

## When to use

Use for cross-project status reporting on an initiative.

## Relevant tools

`query_initiative_updates`, `create_initiative_update`, `update_initiative_update`

## Instructions

<querying>
- Pull prior updates to match tone and set reporting window.
- Can include sub-initiative and related project updates.
</querying>

<drafting>
- Unless asked to post immediately, draft first for review.
- Lead with cross-cutting highlights (wins or risks).
- Summarize meaningful movement across sub-initiatives/projects.
- Call out key dependencies/risks and what's needed.
</drafting>

<health>
- onTrack / atRisk / offTrack — same logic as project updates, applied across the portfolio.
</health>
